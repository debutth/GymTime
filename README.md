# GymTime — version installable via Safari

Ce dossier contient uniquement les fichiers nécessaires à l’application web. Il doit être publié sur une adresse HTTPS avant de pouvoir être ajouté à l’écran d’accueil de l’iPhone.

## Installation sur iPhone

1. Ouvrir l’adresse HTTPS du site dans Safari.
2. Appuyer sur **Partager**, puis **Sur l’écran d’accueil**.
3. Confirmer **Ajouter**.

## Limite du signal en arrière-plan

Le chrono reprend sa durée à partir de l’heure enregistrée et l’état de la séance reste dans le stockage local du téléphone. Le bip web ne peut pas être garanti si iOS suspend ou ferme l’application.
